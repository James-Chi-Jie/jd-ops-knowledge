# 京东会议与沟通记录

本目录用于保存对长期运营有价值的沟通记录，例如：

- 京东招商经理沟通
- 类目运营沟通
- 药师 / 质量负责人沟通
- 活动规则确认
- 广告产品培训
- 供应商 / 厂家控价沟通
- 重要复盘会议

## 记录原则

会议原始流水不必全部进入 GitHub。

只有包含以下内容时建议沉淀：

- 明确的平台规则
- 影响长期经营的政策
- 已确认的费用 / 权限 / 口径
- 形成长期决策的讨论
- 需要后续追踪的待确认事项

高频日常操作仍保存到 Google Drive 运营日志。

## 建议命名

`YYYY-MM-DD-主题.md`

例如：

- `2026-08-20-京东招商沟通.md`
- `2026-08-25-广告后台培训.md`

## 建议结构

```markdown
# 会议主题

日期：
参与方：

## 已确认事实

## 待确认事项

## 对运营的影响

## 决策

## 后续动作
```
