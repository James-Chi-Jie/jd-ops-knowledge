# 京东医药店运营知识库

本仓库用于沉淀京东医药店运营相关的长期稳定知识，作为 ChatGPT / Codex 在京东店铺运营中的权威上下文入口。

## 当前阶段

当前为京东医药店 0-1 启动阶段，重点不是追求快速放量，而是先完成：

1. 入驻与资质确认
2. OTC / RX 合规边界梳理
3. 首批核心商品上架
4. 京东费用、活动、广告和数据口径确认
5. 小预算获取首批真实流量与成交数据
6. 建立日 / 周复盘机制

默认原则：**合规优先、利润先算、小预算验证、数据复盘、风险控制。**

## 存储原则

本仓库只保存长期稳定、可复用的知识，不保存高频变化的数据流水。

### GitHub 保存

- 京东平台稳定规则与已确认口径
- 药品网络销售合规规则
- OTC / RX 商品运营 SOP
- 活动与推广方法
- 指标解释
- 复盘模板
- 历史决策
- 待确认问题

### Google Drive 保存

京东店铺高频变化的运营事实应单独存放在 Google Drive 的京东资料库，例如：

- 商品与 SKU
- 成本、售价、实际实收
- 库存与效期
- 每日订单
- 推广数据
- 活动报名与优惠叠加
- 运营日志
- 日 / 周 / 月复盘

在 Google Drive 的京东资料库尚未建立前，不得假设其目录结构或数据已经存在。

## AI 读取顺序

1. 先读取 `README.md`
2. 再读取 `00-context-map.md`
3. 根据问题类型继续读取对应专项文件
4. 涉及具体商品、价格、成本、活动、推广、订单、库存、实收或经营复盘时，再读取 Google Drive 中京东资料库的入口 README，并按其当前结构读取事实数据

不得仅依据拼多多知识库、历史记忆或经验数字判断京东规则。

## 知识等级

仓库中的重要结论按四类管理：

- **法规确认**：来自现行法律、部门规章、国家药监局等正式监管文件
- **平台确认**：来自京东官方规则中心、京麦后台、招商合同、类目页面或官方通知
- **待确认**：当前无法稳定确认，或可能随店铺类型、类目、招商政策变化
- **运营建议**：属于经营方法和测试策略，不是平台硬规则

任何不确定的信息必须标记为「待确认」，不得把拼多多经验、第三方文章或 AI 生成内容直接写成京东稳定规则。

## 京东与拼多多的隔离原则

可以迁移方法论，但不能直接迁移平台参数。

### 可以迁移

- 合规优先
- 先算利润再参加活动
- 小预算测试
- 不因单日数据做重大决策
- 推广设置止损
- 每日 / 每周复盘
- 运营日志与决策记录

### 不直接迁移

- 拼多多 ROI 阈值
- 全店托管逻辑
- 月卡专享
- 拼多多活动叠加机制
- 拼多多比价机制
- 拼多多标题与搜索规则
- 拼多多自然流量判断阈值

京东的一切平台参数都必须重新验证。
